> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. Execution explicitly authorized by the user after plan approval; Native execution completed, see phase-2a-report.md.

**Goal:** Thực thi S01–S04 bằng registry có contract version, tối ưu P1–P3 và independent score evaluator, giữ nguyên hard correctness và hành vi input 1.0.

**Architecture:** Snapshot/version validation → registry parameter/reference/capability gates → hard preparation → soft expressions → feasibility rồi lexicographic optimization → independent hard validation + score recomputation → versioned result. Evaluator dùng Python thuần, không phụ thuộc compiler/model/OR-Tools. Registry metadata không import solver tại module load.

**Tech Stack:** Python >=3.12, Pydantic 2.14.1, OR-Tools 9.15.6755 optional extra `solver`, pytest 9.1.1, ruff 0.17.2, mypy 2.4.0, uv. Không thêm dependency.
