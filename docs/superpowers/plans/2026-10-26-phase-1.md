# Scheduling Core Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xếp lịch hard-feasible cho tiết đơn/đôi, xác nhận bằng validator độc lập và CLI, không triển khai Phase 2.

**Architecture:** Snapshot revalidated → normalize occurrences → domains/prechecks → Boolean placement CP-SAT → independent validator → output 1.1. Input 1.0 và hash không đổi, output 1.0 vẫn đọc/serialize đúng shape cũ.

**Tech Stack:** Python 3.12+, Pydantic 2.14.1, OR-Tools 9.15.6755 optional extra, pytest/ruff/mypy/uv.

**Spec:** [Phase 1 đã được duyệt](../specs/2026-10-26-phase-1-design.md), [Core First](../../VNEDU_TKB_CORE_FIRST_CODEX.md).

## Global Constraints

- Chỉ Phase 1: một GV/lớp mỗi requirement, duration 1/2; enabled custom rules và nghiệp vụ khác trả UNSUPPORTED_FEATURE.
- Không UI, SQLite, HTTP, vnEdu adapter, repair, soft objective hoặc dữ liệu cá nhân thật.
- Block không vượt buổi/ngày/slot cấm; timed block không vượt gap dương. Mixed minutes là input invalid.
- Room-required/room lock cần size/capacity đủ để verify; không gán null thành phòng vật lý.
- Không copy mã FET/STKB. Mọi lịch xuất phải qua checker Python độc lập.
- Guard mặc định: 10,000 slots, 10,000 occurrences, 100,000 placements, 1,000,000 occupancy terms; workers 1..64, seed 0..2^31-1. Đây là giới hạn vận hành cấu hình được, không quy định trường.

## Review Focus

- Block start khác nhưng trùng tiết thứ hai; symbolic và actual-minute overlap đều được model/checker bắt.
- Lock room-only/time-only, room metadata sai/thiếu và một phòng ngoài scope không bị diễn giải sai.
- Caller mutable/model_construct, unsupported config và resource guards không lọt thành empty valid schedule.
- Output 1.0/1.1 roundtrip, stale fingerprint và validator không tin claim từ result file.
- CLI output symlink/hardlink trùng input, write failure, JSON malformed và optional solver chưa cài.

### Task 1: Normalize và miền xếp

**Files:** `domain/errors.py`, `contracts/capabilities.py`, `solver/options.py`, `preprocessing/{normalize,feasibility}.py`, package init files, `tests/unit/test_preprocessing.py`, synthetic fixtures.

**Interfaces:** `normalize(problem, options=None) -> NormalizedProblem`; `prepare(problem, options=None) -> PreparedProblem`. `NormalizedProblem` chứa snapshot, fingerprint, occurrences, slot tokens. `PreparedProblem` thêm domains theo occurrence. `Placement` chứa start_slot_id, slot_ids, room_id, occupancy tokens. `CoreError` chứa SolveStatus và tuple Diagnostic, không echo records.

- [ ] Implement revalidation, capability, timeline, guarded occurrences, room metadata/domain và necessary checks. Không import OR-Tools.
- [ ] Chạy full pytest và commit; Expected: Phase 0 + preprocessing tests PASS.
